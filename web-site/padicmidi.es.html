PAdicMIDI

Análisis jerárquico, ultramétrico y p-ádico de música simbólica. Un paquete de Python y un applet sin conexión que calculan el invariante Cohπ(p,n) sobre un archivo MIDI.

¿Qué es PAdicMIDI?

PAdicMIDI implementa, por primera vez en software de uso público, el marco del Análisis Aritmético-Topológico de Datos (ATDA) aplicado a música simbólica. Dado un archivo MIDI estándar, el programa construye una torre p-ádica de espacios de patrones Dp,n, define explícitamente el sistema inverso πn+1,n: Sn+1 → Sn, y calcula el invariante de coherencia Cohπ(p,n) junto con su piso nulo arquitectónico 1/p.

El piso 1/p es la cota inferior predicha por la Proposición 3.1 del segundo artículo asociado: las piezas cuya estructura binaria o ternaria satisface las hipótesis (SC) de cobertura entre hermanos y (AI) de inclusión-ancestro alcanzan ese piso exactamente. Las piezas polifónicas se desvían del piso de manera medible, lo cual da origen a un nuevo descriptor cuantitativo de textura musical.

Características principales

Motor verificable

1809 + 417 líneas en Python puro. Reproduce los valores numéricos publicados con tolerancia bit-equivalente en macOS arm64.

CLI y API Python

Cinco entradas de línea de comandos (padicmidi-run-one, -suite, etc.) y una API estable con run_hierarchical_from_midi.

Applet sin conexión

Un único archivo HTML autocontenido (≈ 35 KB) con parser MIDI propio en JavaScript y demo BWV 1007 embebido en base64.

Tests contra los artículos

28 tests divididos en smoke, unitarios, regresión y paper_values. Cada commit verifica los pisos publicados.

Datos con licencia auditada

26 archivos MIDI bajo CC-BY 4.0, CC-BY-SA 3.0, dominio público de EUA, y aportaciones propias en CC0.

Registro autoral

Versión v1.0.0 lista para registro ante INDAUTOR (RPDA-03) con dossier completo, manifiesto SHA-256 y carta de titularidad.

Pruébalo en el navegador

No es necesario instalar nada. Abre el applet, carga la demostración BWV 1007 (preludio de la primera suite para violonchelo de J. S. Bach), elige un primo p y observa cómo el invariante Cohπ(2,n) permanece exactamente en el valor 0.500 a lo largo de toda la torre — el piso nulo arquitectónico.

Instalación del paquete Python

git clone https://github.com/yoyontzin/padicmidi.git
cd padicmidi
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# Analiza el preludio de BWV 1007 con p=2:
padicmidi-run-one data/midi/bwv1007-1.mid bwv1007_pre beats 2 \
    --out resultados/bwv1007/p2

cat resultados/bwv1007/p2/coherence_hier_p2.csv
# n,Coh_pi,Coh_grid,n_samples_n,n_samples_nplus1
# 1,0.5,0.5,1,2
# 2,0.5,0.5,2,4
# 3,0.5,0.5,4,8
# ...

Uso programático

from padicmidi import run_hierarchical_from_midi

resultado = run_hierarchical_from_midi(
    midi_path="data/midi/bwv1007-1.mid",
    p=2, axis="beats", nmax=5, seed=42,
)
for fila in resultado["coherence"]:
    print(fila)

Para reproducir bit-equivalentemente los CSV publicados, instala las dependencias congeladas: 

pip install -r requirements-pinned.txt
