What is PAdicMIDI?

PAdicMIDI is the first publicly released software implementation of the Arithmetic-Topological Data Analysis (ATDA) framework applied to symbolic music. Given a Standard MIDI file, the program builds a p-adic tower of pattern spaces Dp,n, explicitly defines the inverse system πn+1,n: Sn+1 → Sn, and computes the coherence invariant Cohπ(p,n) together with its architectural null floor 1/p.

The floor 1/p is the lower bound predicted by Proposition 3.1 of the second companion paper: pieces whose binary or ternary structure satisfies the (SC) sibling-cover and (AI) ancestor-inclusion hypotheses attain the floor exactly. Polyphonic pieces deviate from the floor in a measurable way, yielding a new quantitative descriptor of musical texture.

Key features

Verifiable engine

1809 + 417 lines of pure Python. Reproduces published numerical values to bit equivalence on macOS arm64.

CLI and Python API

Five command-line entry points (padicmidi-run-one, -suite, …) and a stable API via run_hierarchical_from_midi.

Offline applet

A single self-contained HTML file (~35 KB) with its own JavaScript MIDI parser and the BWV 1007 demo embedded in base64.

Tests against the papers

28 tests in four tiers (smoke, unit, regression, paper_values). Every commit verifies the published floors.

Audited data licences

26 MIDI files under CC-BY 4.0, CC-BY-SA 3.0, US Public Domain, and original CC0 contributions by the author.

Version v1.0.0 ready for INDAUTOR registration (RPDA-03 form), with full dossier, SHA-256 manifest and authorship statement.

Try it in your browser

No installation required. Open the applet, load the bundled BWV 1007 demo (the prelude of J. S. Bach's first cello suite), choose a prime p and watch the invariant Cohπ(2,n) stay exactly at 0.500 across the whole tower — the architectural null floor.

Python package installation

git clone https://github.com/yoyontzin/padicmidi.git
cd padicmidi
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# Analyse the prelude of BWV 1007 with p=2:
padicmidi-run-one data/midi/bwv1007-1.mid bwv1007_pre beats 2 \
    --out results/bwv1007/p2

cat results/bwv1007/p2/coherence_hier_p2.csv
# n,Coh_pi,Coh_grid,n_samples_n,n_samples_nplus1
# 1,0.5,0.5,1,2
# 2,0.5,0.5,2,4
# 3,0.5,0.5,4,8
# ...

Programmatic usage

from padicmidi import run_hierarchical_from_midi

result = run_hierarchical_from_midi(
    midi_path="data/midi/bwv1007-1.mid",
    p=2, axis="beats", nmax=5, seed=42,
)
for row in result["coherence"]:
    print(row)

For bit-equivalent reproduction of the published CSVs, install the pinned dependencies: 

pip install -r requirements-pinned.txt
