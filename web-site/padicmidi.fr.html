Qu'est-ce que PAdicMIDI ?

PAdicMIDI met en œuvre, pour la première fois dans un logiciel à usage public, le cadre de l'analyse arithmético-topologique de données (ATDA) appliquée à la musique symbolique. À partir d'un fichier MIDI standard, le programme construit une tour p-adique d'espaces de motifs Dp,n, définit explicitement le système inverse πn+1,n: Sn+1 → Sn, et calcule l'invariant de cohérence Cohπ(p,n) ainsi que son plancher nul architectonique 1/p.

Le plancher 1/p est la borne inférieure prédite par la Proposition 3.1 du second article associé : les pièces dont la structure binaire ou ternaire vérifie les hypothèses (SC) de couverture entre frères et (AI) d'inclusion-ancêtre atteignent ce plancher exactement. Les pièces polyphoniques s'en écartent de manière mesurable, ce qui donne lieu à un nouveau descripteur quantitatif de texture musicale.

Caractéristiques principales

Moteur vérifiable

1809 + 417 lignes en Python pur. Reproduit les valeurs numériques publiées avec une tolérance bit-équivalente sur macOS arm64.

CLI et API Python

Cinq points d'entrée en ligne de commande (padicmidi-run-one, -suite, etc.) et une API stable avec run_hierarchical_from_midi.

Applet hors-ligne

Un unique fichier HTML autonome (≈ 55 ko) avec parseur MIDI intégré en JavaScript et démo BWV 1007 incluse en base64.

Tests contre les articles

28 tests répartis en smoke, unitaires, régression et paper_values. Chaque commit vérifie les planchers publiés.

Données sous licences auditées

26 fichiers MIDI sous CC-BY 4.0, CC-BY-SA 3.0, domaine public des États-Unis, et contributions propres en CC0.

Enregistrement d'auteur

L'essayer dans le navigateur

Aucune installation requise. Ouvrez l'applet, chargez la démonstration BWV 1007 (prélude de la première suite pour violoncelle de J. S. Bach), choisissez un nombre premier p et observez comment l'invariant Cohπ(2,n) reste exactement à la valeur 0,500 sur toute la tour — le plancher nul architectonique.

L'applet s'exécute entièrement à l'intérieur de votre navigateur. Aucune requête réseau, aucun cookie, aucune télémétrie. Votre fichier MIDI ne quitte jamais votre ordinateur.

Installation du paquet Python

git clone https://github.com/yoyontzin/padicmidi.git
cd padicmidi
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# Analyse le prélude de BWV 1007 avec p=2 :
padicmidi-run-one data/midi/bwv1007-1.mid bwv1007_pre beats 2 \
    --out resultats/bwv1007/p2

cat resultats/bwv1007/p2/coherence_hier_p2.csv
# n,Coh_pi,Coh_grid,n_samples_n,n_samples_nplus1
# 1,0.5,0.5,1,2
# 2,0.5,0.5,2,4
# 3,0.5,0.5,4,8
# ...

Utilisation programmatique

from padicmidi import run_hierarchical_from_midi

resultat = run_hierarchical_from_midi(
    midi_path="data/midi/bwv1007-1.mid",
    p=2, axis="beats", nmax=5, seed=42,
)
for ligne in resultat["coherence"]:
    print(ligne)

Pour reproduire de manière bit-équivalente les CSV publiés, installez les dépendances figées : 

pip install -r requirements-pinned.txt
